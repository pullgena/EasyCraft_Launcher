# EasyCraft Launcher 이용약관

시행일: 2026-09-19
버전: v0.4.28

## 1. 목적
이 약관은 EasyCraft Launcher(이하 “EasyCraft”)를 이용할 때 필요한 기본 조건과 운영 원칙을 안내합니다.

## 2. 서비스 성격
EasyCraft는 Minecraft Java Edition 실행, 인스턴스 관리, Modrinth 콘텐츠 설치 및 업데이트 기능을 제공하는 비공식 서드파티 런처입니다. Microsoft, Mojang Studios, Minecraft, Modrinth 또는 GitHub의 공식 제품이나 제휴 제품이 아닙니다.

## 3. 이용 조건
1. Minecraft를 실행하려면 정식 Microsoft/Minecraft 계정을 사용해야 합니다.
2. 사용자는 Microsoft, Minecraft 및 연결되는 제3자 서비스의 약관을 함께 준수해야 합니다.
3. 타인의 계정이나 인증정보를 허가 없이 사용해서는 안 됩니다.
4. 인증 또는 네트워크 정책을 우회하거나 타인의 시스템에 무단 접근하는 용도로 EasyCraft를 사용해서는 안 됩니다.

## 4. 로그인 방식
EasyCraft v0.4.28부터 EasyCraft 자체 계정 로그인 기능을 제공하지 않습니다. Minecraft 실행 인증은 현재 PC에서 Microsoft/Minecraft 인증 절차를 직접 진행합니다. Microsoft 계정 비밀번호를 EasyCraft 자체 서버에 저장하지 않습니다.

## 5. 업데이트 및 기능 변경
EasyCraft는 안정성, 보안, 호환성 또는 기능 개선을 위해 자동 업데이트를 제공할 수 있습니다. 외부 서비스의 정책 또는 API 변경으로 일부 기능이 달라지거나 일시적으로 작동하지 않을 수 있습니다.

## 6. 데이터 및 백업
인스턴스, 월드, 모드, 설정 등 로컬 Minecraft 데이터의 백업 책임은 사용자에게 있습니다. 중요한 월드는 별도로 백업하는 것을 권장합니다.

## 7. 책임 제한
EasyCraft는 외부 서비스 장애, Minecraft 버전 변경, 모드 충돌, 사용자 환경, 네트워크 또는 운영체제 문제로 인한 모든 결과를 보장할 수 없습니다.
