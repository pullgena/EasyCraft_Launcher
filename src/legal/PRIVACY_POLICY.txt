# EasyCraft Launcher 개인정보처리방침

시행일: 2026-09-18
버전: v0.4.27

EasyCraft는 기능 제공에 필요한 범위에서만 정보를 처리하도록 설계합니다. 로그인 방식에 따라 처리되는 정보가 다릅니다.

## 1. 처리할 수 있는 정보
### EasyCraft 계정 로그인 사용 시
- EasyCraft 계정 ID
- 비밀번호 원문이 아닌 로그인 검증용 SRP 정보
- EasyCraft 세션 식별정보
- 연결된 Minecraft 닉네임 및 UUID
- 클라이언트에서 암호화한 Microsoft/Minecraft 인증 보관함 데이터
- EasyCraft 계정에 연결된 Microsoft refresh token의 서버 암호화본
- 서비스 운영 과정에서 호스팅 업체 또는 터널 서비스가 자동으로 생성할 수 있는 접속 로그(IP 주소, 요청 시각 등)
- 사용자가 직접 “오류 로그 서버로 보내기”를 누른 경우, 선택한 인스턴스의 EasyCraft/Minecraft 실행 로그, 런처 버전, Minecraft/로더 버전, 운영체제 종류·버전 및 오류 보고서 식별정보

### EasyCraft 계정 없이 Microsoft로 시작할 때
- Minecraft 닉네임 및 UUID
- Microsoft/Minecraft 인증 갱신에 필요한 토큰 정보
- 스킨 표시를 위한 Minecraft 프로필 정보

이 모드의 Microsoft/Minecraft 인증정보는 EasyCraft 계정 서버에 업로드하지 않고 현재 PC의 EasyCraft 사용자 데이터 영역에 저장합니다. 가능한 경우 운영체제의 Electron safeStorage를 이용해 보호합니다.

## 2. 처리 목적
- EasyCraft 계정 로그인 및 세션 유지
- 연결된 Minecraft 계정 동기화
- Minecraft 실행 및 인증 갱신
- 스킨/프로필 표시
- 서비스 보안 및 오류 대응
- 사용자가 요청한 오류 로그 수집·분석 및 실행 문제 진단

### EasyCraft 웹 로그인/인증 사이트를 사용할 때
- 런처가 발급한 일회용 인증 링크/웹 세션 정보
- Microsoft가 발급한 OAuth access token 및 refresh token
- Minecraft Java 프로필 이름 및 UUID
- 토큰 저장·갱신 시각

EasyCraft ID와 비밀번호는 웹사이트에서 입력하지만 비밀번호 원문은 브라우저의 SRP 계산에만 사용되며 서버로 전송하지 않습니다. Microsoft 비밀번호는 EasyCraft 인증 사이트에 입력하지 않습니다. 사용자는 Microsoft 공식 로그인 페이지에서 직접 인증합니다. 인증 완료 후 refresh token은 EasyCraft Account Server가 서버 전용 키로 AES-256-GCM 암호화하여 저장하며, 런처에는 refresh token을 전달하지 않습니다. 런처가 생성하는 웹 로그인 링크와 폴링 토큰은 짧은 시간만 유효하며 한 번 사용하면 폐기됩니다.

## 3. Microsoft 비밀번호
EasyCraft는 Microsoft 계정 비밀번호를 자체 서버에 저장하도록 설계하지 않습니다. Microsoft 인증은 Microsoft/Xbox/Minecraft 인증 흐름을 통해 처리됩니다.


### 토큰 상태 및 서버 로그
EasyCraft Account Server는 Microsoft refresh token의 생성·교체 여부를 운영 콘솔에서 확인할 수 있도록 토큰 원문이 아닌 SHA-256 기반의 짧은 fingerprint, EasyCraft 계정 ID, 저장/갱신 시각 및 예상 남은 기간을 기록할 수 있습니다. refresh token 원문은 콘솔 로그에 출력하지 않습니다.

## 4. EasyCraft 계정 보관함
EasyCraft 계정 동기화 기능에서는 호환성/복구용 클라이언트 암호화 보관함과 함께 Microsoft refresh token을 계정 서버의 전용 암호화 키로 AES-256-GCM 암호화해 저장할 수 있습니다. 서버는 이 refresh token을 사용해 Microsoft/Xbox/Minecraft 인증을 자동 갱신하고, 다른 PC에는 refresh token이 아닌 현재 Minecraft 실행에 필요한 단기 access token만 전달합니다. Microsoft 비밀번호는 서버에 저장하지 않습니다.


### 오류 로그 서버 전송
오류 로그 전송은 자동으로 이루어지지 않으며, EasyCraft 계정으로 로그인한 사용자가 로그 화면의 전송 버튼을 직접 누른 경우에만 수행됩니다. 전송되는 로그에는 사용자 PC의 파일 경로, 모드/파일 이름, 실행 환경 정보 등이 포함될 수 있습니다. EasyCraft는 전송 전에 Microsoft/Minecraft access token·refresh token, EasyCraft 세션 키·서명 등 알려진 인증정보 패턴을 자동으로 마스킹하며, 서버에서도 다시 한 번 마스킹합니다.

전송된 보고서는 EasyCraft Account Server의 `data/error-reports/` 영역에 저장될 수 있으며 오류 분석 및 수정 목적으로 사용됩니다. 공개 GitHub Issue 등에 원본 로그를 그대로 게시하지 마십시오.

## 5. 보유 및 삭제
- 로컬 로그인 정보: 사용자가 로그아웃하거나 EasyCraft 사용자 데이터를 삭제할 때 제거할 수 있습니다.
- EasyCraft 계정 세션: 로그아웃, 만료 또는 서버 정리 정책에 따라 제거됩니다.
- EasyCraft 계정 및 연결 보관함: 계정 삭제가 처리되면 삭제하는 것을 원칙으로 합니다.
- 사용자가 전송한 오류 로그: 오류 분석 및 서비스 개선에 필요한 기간 동안 보관한 뒤 운영자가 삭제합니다. 공개 운영 전 실제 보관기간을 정해 고지해야 합니다.
- 법령상 별도 보관 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

현재 계정 삭제 절차는 `계정 및 개인정보 삭제 안내` 문서를 확인해 주세요.

## 6. 외부 서비스와의 통신
기능 제공 과정에서 다음 서비스와 통신할 수 있습니다.
- Microsoft / Xbox / Minecraft Services: 계정 인증 및 Minecraft 이용 권한 확인
- Mojang/Minecraft 서버: 버전 정보, 프로필 및 게임 파일 관련 정보
- Modrinth: 모드, 리소스팩, 셰이더, 모드팩 검색 및 설치
- GitHub: EasyCraft 업데이트 확인 및 다운로드
- ngrok: EasyCraft 계정 서버의 HTTPS 터널 연결
- Weird Host: EasyCraft 계정 서버 호스팅

각 외부 서비스에서 처리되는 정보는 해당 서비스의 정책을 함께 적용받을 수 있습니다.

## 7. 보안 조치
EasyCraft는 현재 구조에서 다음과 같은 보호 방식을 사용합니다.
- EasyCraft 비밀번호 원문을 서버 로그인 검증값으로 그대로 저장하지 않음
- SRP 기반 EasyCraft 계정 인증
- Microsoft/Minecraft 보관함 암호화
- 서버 저장 Microsoft refresh token의 AES-256-GCM 암호화 및 서버 키 분리 보관
- 서명된 계정 서버 요청/응답 검증
- 로컬 인증정보에 Electron safeStorage 사용(지원되는 환경)
- HTTPS 터널을 통한 계정 서버 연결

어떠한 시스템도 절대적인 보안을 보장할 수 없으므로 계정 비밀번호와 인증정보를 다른 사람과 공유하지 마십시오.

## 8. 이용자의 권리
사용자는 자신의 EasyCraft 계정 및 연결된 보관함의 삭제를 요청할 수 있습니다. 로컬에 저장된 로그인 정보는 로그아웃 또는 EasyCraft 데이터 삭제를 통해 제거할 수 있습니다.

## 9. 아동의 개인정보
공개 계정 서비스를 운영할 경우 만 14세 미만 이용자의 개인정보 처리에는 법정대리인 동의 등 별도 절차가 필요할 수 있습니다. 해당 절차가 마련되지 않은 상태에서는 만 14세 미만 이용자의 EasyCraft 계정 생성·사용을 받지 않는 운영이 권장됩니다.
