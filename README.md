# EasyCraft Launcher 0.4.13-beta.6

Windows Minecraft Java Edition 런처의 EasyCraft 코드 로그인 실험 버전입니다.


## Beta 6 시작 업데이트 멈춤 수정

- 업데이트 확인은 최대 8초 동안만 시작 화면을 막습니다.
- GitHub 또는 학교 네트워크가 응답하지 않아도 EasyCraft 메인 화면으로 진입합니다.
- Mojang 버전 API가 느린 경우에도 시작 화면 안전 타이머가 독립적으로 동작합니다.
- 설정의 `업데이트 확인`에서 나중에 다시 확인할 수 있습니다.

## Beta 6 코드 로그인

1. EasyCraft 설정에서 배포한 인증 사이트 URL을 저장합니다.
2. 로그인 → `EasyCraft 코드 로그인 · BETA 6`를 선택합니다.
3. 학교 PC에서 인증 사이트를 열고 Microsoft 로그인합니다. 학교에서 막히면 휴대폰에서 같은 사이트를 사용합니다.
4. 사이트에 표시된 `EC-XXXX-XXXX-XXXX` 코드를 EasyCraft에 입력합니다.
5. 코드는 5분 동안 한 번만 사용할 수 있습니다.

인증 사이트 배포 방법은 `AUTH_SITE_SETUP.md`를 확인하세요.
