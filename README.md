# EasyCraft Launcher 0.4.13-beta.4

Microsoft 공식 Device Code Flow를 이용한 `microsoft.com/link` 코드 로그인 테스트 버전입니다.

- 설정에서 EasyCraft용 Microsoft Application (client) ID를 지정합니다.
- 로그인 화면에서 짧은 코드를 발급합니다.
- 휴대폰/다른 PC에서 `https://microsoft.com/link`를 열어 코드를 입력합니다.
- 인증 완료를 EasyCraft가 자동으로 감지합니다.
- Minecraft Java 소유권 확인은 기존과 동일하게 진행됩니다.

자세한 설정은 `AUTH_SETUP.md`를 참고하세요.
