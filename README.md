# EasyCraft Launcher v0.4.28

EasyCraft Launcher는 Minecraft Java Edition용 비공식 커스텀 런처입니다.

## v0.4.28 인증 방식
- EasyCraft 자체 계정 로그인 기능 없음
- Microsoft/Minecraft 계정으로 현재 PC에서 직접 로그인
- 로그인 정보는 로컬 사용자 데이터에 저장되며 지원되는 환경에서 Electron safeStorage로 보호
- EasyCraft 계정 서버를 통한 로그인/토큰 동기화 사용 안 함

## 주요 기능
- Minecraft 인스턴스 생성/설정/실행
- Fabric / Forge / NeoForge / Quilt 지원
- Modrinth 모드, 리소스팩, 셰이더, 모드팩 관리
- 실시간 실행 로그
- GitHub Releases 자동 업데이트
