# EasyCraft Launcher 0.4.13-beta.2

학교/공용 PC에서 Microsoft 로그인 창이 막히는 환경을 시험하기 위한 베타입니다.

## 휴대폰에서 로그인 (Beta 2)
1. EasyCraft에서 `휴대폰에서 로그인 · BETA 2`를 선택합니다.
2. 표시된 Microsoft 로그인 링크를 복사해 휴대폰 또는 다른 PC로 보냅니다.
3. 다른 기기에서 정상 Microsoft 로그인을 완료합니다.
4. 로그인 후 브라우저 주소창의 마지막 `https://login.live.com/oauth20_desktop.srf?...` 주소 전체를 복사합니다.
5. EasyCraft의 입력란에 붙여넣고 `인증 완료`를 누릅니다.

비밀번호는 EasyCraft에 입력하거나 저장하지 않습니다. Minecraft Java Edition 계정과 소유권 확인은 기존과 동일하게 수행합니다.
