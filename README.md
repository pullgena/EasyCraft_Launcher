# EasyCraft Launcher 0.4.13-beta.3

학교나 공용 PC에서 Microsoft 로그인 창을 사용하기 어려운 환경을 위한 다른 기기 로그인 실험 버전입니다.

## 다른 기기 로그인 Beta 3

1. EasyCraft에서 `휴대폰에서 로그인 · BETA 3`을 선택합니다.
2. 표시된 Microsoft 로그인 링크를 휴대폰이나 다른 PC에서 엽니다.
3. Microsoft 계정으로 정상 로그인합니다.
4. 로그인 완료 후 주소창에서 `code=` 뒤부터 `&state=` 앞까지의 일회용 인증 코드를 복사합니다.
5. EasyCraft의 `Microsoft 인증 코드` 칸에 붙여넣고 `인증 완료`를 누릅니다.

전체 로그인 완료 URL을 붙여넣어도 EasyCraft가 자동으로 code 값을 추출합니다. Microsoft 비밀번호는 EasyCraft에 입력하지 않습니다.

> 이 기능은 정식 Microsoft/Minecraft 인증을 우회하지 않습니다. Minecraft Java Edition 소유권 확인은 기존과 동일하게 진행됩니다.
